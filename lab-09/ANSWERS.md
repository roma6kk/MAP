# Лабораторная 8 — ответы на вопросы

1. **Чем Hive отличается от SQFLite? Когда что выбирать?** Hive — NoSQL key-value база на чистом Dart: быстрая, без SQL, хранит объекты через адаптеры, есть шифрование. SQFlite — реляционная SQLite: JOIN, индексы, сложные запросы, миграции. Hive — для кэша, настроек, небольших коллекций; SQFlite — для связанных данных и сложных выборок.
2. **Как Hive обеспечивает типобезопасность?** `Box<T>` и `TypeAdapter<T>`: типы фиксированы при компиляции, объекты читаются обратно в тот же класс.
3. **Что такое адаптер в Hive и зачем он нужен?** `TypeAdapter` описывает, как записать/прочитать объект в бинарном виде (`read`/`write`, уникальный `typeId`). Без него Hive хранит только примитивы, списки и Map.
4. **Как работает шифрование в Hive? Где хранится ключ?** `HiveAesCipher` (AES-256-CBC) передаётся в `openBox(encryptionCipher:)`. Ключ (32 байта) здесь хранится в `flutter_secure_storage` (Android Keystore / iOS Keychain), не рядом с данными.
5. **Как сжатие влияет на производительность и размер?** Уменьшает файл (убирает удалённые и перезаписанные записи), но сама операция тяжёлая: перезаписывает файл. Зовётся редко.
6. **Что такое compactionStrategy в Hive?** Параметр `openBox`: функция `(entries, deletedEntries) => bool`; если вернула true, бокс автоматически сжимается. По умолчанию — когда удалённых записей ≥ 60 и они ≥ 15 % от всех.
7. **Как Hive работает с изолятами?** Каждый изолят имеет свою память, бокс, открытый в одном, в другом не виден. Нужно открыть бокс заново (риск конфликта файла) или обмениваться данными сообщениями; официального межизолятного доступа нет.
8. **Как мигрировать данные при изменении схемы?** Поля в адаптере нумеруются; новые поля читаются с значением по умолчанию, если их нет. Для крупных изменений — читать старые данные, преобразовать и записать в новый бокс/версию.
9. **Чем Hive.openBox() отличается от Hive.openLazyBox()? Когда что использовать?** `openBox` загружает все значения в память — быстро, подходит для небольших данных. `LazyBox` держит в памяти только ключи, значения читаются по запросу (`await get`) — для больших данных.
10. **Как хранить список объектов в Hive? Какие ограничения?** `Box<List>` / поле `List<T>` в адаптере; `box.values`. Ограничения: все элементы должны иметь зарегистрированные адаптеры, при изменении списка надо записать его заново (`put`), нет запросов внутри.
11. **Что произойдёт, если не закрыть box перед завершением приложения?** Данные уже записаны при `put` (запись идёт в файл сразу), но сжатие/состояние могут не завершиться; при падении в процессе записи файл может быть повреждён — Hive пробует восстановиться и отбросить плохие записи.
12. **Как удалить все данные из box? Чем box.clear() отличается от box.deleteFromDisk()?** `clear()` удаляет все записи, бокс остаётся открытым и файл остаётся (пустой). `deleteFromDisk()` закрывает бокс и удаляет его файл.
13. **Как реализовать поиск и сортировку данных в Hive? Сравните с SQFLite.** Нет запросов: `box.values.where(...)`, `.toList()..sort(...)` в памяти. SQFlite делает это на стороне БД с индексами (`WHERE`, `ORDER BY`), лучше на больших объёмах.
14. **Как ограничить доступ к CRUD-операциям в зависимости от роли пользователя?** Проверка роли перед операцией (`user.canEdit`) в UI (кнопки скрыты) и перед записью (в форме и сервисе). Hive сам прав не знает.
15. **Как связать избранное с конкретным пользователем? Приведите структуру данных.** Бокс `favorites`, ключ `'userId:shipmentId'`, значение `Favorite(userId, shipmentId, addedAt)`. Выборка избранного — фильтр по `userId`.
16. **Какие данные нельзя хранить в Hive? Приведите примеры.** Большие файлы/видео/изображения (хранить путь), реляционные данные с JOIN, объекты без адаптера (виджеты, `Function`), пароли и секреты открытым текстом.
17. **Как Hive работает с асинхронностью? Нужно ли использовать изоляты?** API асинхронное (`openBox`, `put`, `compact` возвращают Future), чтение из открытого `Box` — синхронное из памяти. Изоляты обычно не нужны, кроме очень больших объёмов.

## Что реализовано
- Таблицы (боксы): `users` (роли admin/manager/user), `shipments` (картинка-путь, имя, статус, откуда/куда, даты, описание), `favorites` (связь user→shipment).
- Просмотр, добавление, редактирование, удаление посылок — admin/manager; избранное — для всех (по текущему пользователю).
- Шифрование боксов, ключ в secure storage, демонстрация чтения неверным ключом и сжатие — экран «Security».
